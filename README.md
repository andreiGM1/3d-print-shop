# LayerByLayer — Studio de Printare 3D & Prototipare

Aplicație web completă cu simulator interactiv de cost per gram/material (PLA, PETG, ABS, Rășină UV 8K) și formular rapid de comandă pentru piese și servicii Etsy.

## Cum rulezi proiectul
- **Vizualizare Imediată:** Fă dublu-click pe `index.html` pentru a deschide site-ul în browser.
- **Hosting Live:** Încarcă fișierele (`index.html`, `styles.css`, `app.js`) pe Cloudflare Pages sau Vercel.
- **Next.js:** Componenta React este disponibilă în `page.tsx`.
